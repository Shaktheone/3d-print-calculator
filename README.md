# 3D Printing Cost Calculator – Georgia (GEL ₾)

Offline-first web app for calculating 3D printing costs. All prices in Georgian Lari (₾).

## Features
- **Printers & Materials** — manage your fleet and filament inventory
- **Order Calculator** — live cost breakdown with material, electricity, print time, overheads, margin, tax
- **Order History** — track, filter, and update order statuses
- **Monthly Overheads & One-time Expenses** — rent, tools, nozzles, repairs
- **Statistics** — Chart.js dashboards (revenue, material costs, top printers/clients)
- **Dark Mode** — toggle, persists across sessions
- **Export/Import** — JSON backup & CSV orders
- **100% Offline** — IndexedDB storage, no backend required

## Tech Stack
HTML · CSS · Bootstrap 5.3 · Vanilla JavaScript · IndexedDB · Chart.js
